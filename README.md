# WET - Water Everyday Tracker 💧
A cute Kotlin Android app to help you stay hydrated every day!

## Features (Planned for MVP)
✅ Track water intake  
✅ Set daily goal  
✅ Visual progress bar  
✅ Gentle hydration reminders

## Tech Stack
- Kotlin
- Android SDK
- Jetpack Compose
- Room DB
